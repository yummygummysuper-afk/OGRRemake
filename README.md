# OG ROOMS: Remake

Готовая версия для GitHub Pages. Сборка и установка зависимостей не нужны.

## Публикация с iPhone

1. Скачайте и распакуйте `OG-ROOMS-GitHub.zip` в приложении «Файлы» (нажмите на ZIP).
2. На https://github.com/new создайте репозиторий `og-rooms`, выберите Public и включите Add README.
3. В репозитории выберите Add file → Upload files → choose your files. Выберите файлы ИЗ распакованной папки. Не загружайте сам ZIP и не помещайте файлы в дополнительную подпапку.
4. Нажмите Commit changes. Файл index.html должен быть виден рядом с README.md в корне репозитория.
5. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, папка /(root) → Save.
6. Дождитесь успешной публикации. Ссылка появится на странице Settings → Pages и будет вида https://ВАШ-ЛОГИН.github.io/og-rooms/.
7. Откройте эту ссылку в Safari. Поделиться → На экран «Домой». Если есть переключатель «Открывать как веб-приложение», включите его. Запускайте игру с новой иконки. Старую иконку Cloudflare удалите.

Если нужные пункты GitHub не видны, в меню Safari выберите «Запросить настольный веб-сайт». Публикация не мгновенная; дождитесь завершения задания Pages в разделе Actions.

Важно: GitHub Pages — отдельный хостинг, он не зависит от тестового сервера в чате. Доступность зависит от GitHub и вашей сети. Репозиторий Public будет доступен другим людям; этот пакет содержит только игру и лицензию движка, без учётных данных.

После успешного первого запуска service worker сохраняет файлы для офлайн-игры. Если загрузка не завершилась или iOS очистила хранилище, понадобится подключение. В новой версии сохранённая игра не подменяется страницей ошибки сервера.

## Управление

Телефон: джойстик слева — движение; жест по сцене — обзор; E — дверь/укрытие; F — свет; удерживать R — зарядка; II — пауза.

ПК: WASD, мышь, E, F, R, Shift, Esc.

Испытать сущность сразу: Пауза → Испытания сущностей.

## О сборке

Это браузерный фанатский прототип Rooms, не проект Roblox Studio. В index.html встроены скрипты, стили, Three.js и процедурные ресурсы. Остальные файлы нужны для устанавливаемого веб-приложения и офлайн-режима.

Кредиты по заданию: Vex Studio — textures; modify4ik — animations, models, scripting; Kimi — GUI. Используемые в прототипе геометрия, текстуры и звуки созданы программно. Three.js: MIT, см. THREE-LICENSE.txt.
